Design Choices

Colour: Deep blue is used as the primary colour to create a professional appearance, while orange is used as an accent for important actions.

Typography: A system font stack is used for fast loading and good readability. A line-height of 1.6 makes paragraphs comfortable to read.

Layout: The content width is limited to 800px so that text remains easy to read. White content cards are placed over a light background to create visual separation.

Maintainability: Colours are stored in CSS custom properties, allowing the theme to be changed easily from one place.
