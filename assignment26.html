Box Model of .my-box

Hello
Margin: 30px
Border: 10px
Padding: 20px
Content
200 × 80px

Calculation

The default value of box-sizing is content-box.

Total Width 200 + (20 × 2) + (10 × 2) = 260px
Including 60px margin = 320px
Total Height 80 + (20 × 2) + (10 × 2) = 140px
Including 60px margin = 200px

With box-sizing: border-box

With box-sizing: border-box, the declared width: 200px includes the padding and border. Therefore, the overall box width remains 200px, while the content area becomes 140px wide.

A common practice is to use:

* { box-sizing: border-box; }

Tip: Open DevTools (F12) → Elements → Computed to inspect the box model of an element.
